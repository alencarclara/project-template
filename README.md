# project-template

GitHub template repository for new projects.
Click "Use this template" to start a project with my baseline already in place.

## Planned contents
- CI that runs lint and tests
- Dependabot, CodeQL and secret scanning
- Pull request and issue templates, CODEOWNERS
- A short CLAUDE.md starter (from `ai-library`)

## Related
- `ai-library`: agents, flows and templates used to set up projects.
